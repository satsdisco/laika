# Laika — Russian Alphabet & Cyrillic Coach

A friendly, dark-mode starter for learning the Russian Cyrillic alphabet, beginner vocabulary, and practical phrases with Laika, a vector space-pup tutor.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`; preview with `npm run preview`.

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS (configuration included; interface styling uses a small custom CSS layer)
- Lucide icons

## Deploy

### Vercel
Import this repository in Vercel. Framework preset: Vite. Build command: `npm run build`; output directory: `dist`.

### Cloudflare Pages
Connect the repository in Cloudflare Pages. Build command: `npm run build`; build output directory: `dist`.

## Learning features

- All 33 Russian letters, letter categories, transliteration and English-oriented sound hints
- Letter explorer with category filters and search
- Interactive letter flashcards
- Multiple-choice sound quiz with session score
- Beginner vocabulary and practical phrases with stress accents
- Laika vector mascot and beginner pronunciation tips

Pronunciation hints are approximations for English speakers, not a substitute for listening to native speech. Audio playback is not implemented in this starter.
